# 性能基准与生成语料

运行完整流程：

```sh
moon test --target all --filter '*corpus*'
python benchmarks/run.py --iterations 20000 --repeats 5
```

主入口 `run.py` 编译 MoonBit JavaScript release 程序，先丢弃一次运行，再在五个独立 Node.js 进程中采样。程序用标准库单调时钟记录微秒，编译耗时不计入；每个新进程中的 JIT 影响保留在样本中。结果写到同目录的 `results.json`，包含环境、命令、原始样本、操作数、校验和及中位数。解析和归一化使用八个固定表达式，换算使用同一浓度单位对。引擎初始化单独执行 100 次，其余场景默认各 20000 次。

这些小型基准用于观察解析、缓存和转换器复用的成本，不代表完整应用吞吐量。实际数值以结果文件为准。重复解析与复用转换器的结果校验和必须一致；不设置受机器负载影响的性能通过阈值。

`corpus_test.mbt` 使用种子 563 和固定的整数递推，生成 5000 个带随机比例因子、前缀、指数、分母和注释的表达式。每条检查独立系数公式、往返转换及大小写不敏感模式；另执行 1000 条不完整除法输入。语料在四后端验收中实际运行，原始上游测试期望保持不变。
